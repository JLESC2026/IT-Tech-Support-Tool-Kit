PortableApps - legitimate portable utilities
============================================

The toolkit does NOT include third-party programs. Download the official portable version of
each tool yourself, unzip it into the matching folder and the "Portable Tools" buttons in the
toolkit will list and launch it. Always download from the vendor's own site, and read each
tool's licence (some tools restrict commercial use or redistribution on a USB drive).

How it works
------------
- Put each program in its own sub-folder, for example  PortableApps\Disk-Health\CrystalDiskInfo\DiskInfo64.exe
- The launcher searches up to 3 levels deep for .exe, .bat, .cmd and .lnk files and skips uninstallers.
- With nothing in a folder, the button shows the suggested tools and their download pages instead.
- Keep the downloaded ZIPs out of this folder; only the unzipped program is needed.
- Links can change over time. If one no longer works, search for the tool's name on its official site.
