Other manufacturers
===================
Put official utilities for any other brand here (Xerox, Ricoh, Kyocera, Samsung, Lexmark,
Konica Minolta ...). Create one sub-folder per brand if you like - the toolkit searches
this folder and sub-folders up to 2 levels for .exe, .msi, .bat, .cmd, .lnk and .ps1 files.
With nothing here, the "Other" button opens a web search for printer drivers.

Only use installers downloaded from the manufacturer and respect their licence terms.
